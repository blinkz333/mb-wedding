# Gallery images

วางรูป pre-wedding ไว้ในโฟลเดอร์นี้ได้เลย รองรับนามสกุล: `.jpg` `.jpeg` `.png` `.webp`

- รูปจะถูก import อัตโนมัติ (ไม่ต้องแก้โค้ด)
- เรียงตามชื่อไฟล์ ตั้งชื่อเป็น `01.jpg`, `02.jpg`, ... เพื่อคุมลำดับ
- แนะนำรูปแนวตั้ง (portrait) อัตราส่วนราว 3:4 กว้าง ~1200px ต่อรูป
- ใส่กี่รูปก็ได้ เลขคู่จะได้แถวบน/ล่างเท่ากันสวยที่สุด (แนะนำ 6–12 รูป)

ถ้าโฟลเดอร์นี้ยังว่าง เว็บจะใช้รูปสำรองไปก่อน
